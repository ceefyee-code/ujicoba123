# 📖 Modul & Kamus Belajar Git & GitHub Interaktif

Selamat datang di modul belajar interaktif Git & GitHub yang dirancang khusus untuk pemula dengan pendekatan praktis via **Visual Studio Code (UI & Terminal)**.

---

## 🚀 Cara Membuka Modul Ini

Ada beberapa cara mudah untuk membuka modul belajar ini:

### Cara 1: Langsung Dobel Klik (Paling Mudah)
1. Buka folder `modulbelajar` di Finder / File Explorer laptopmu.
2. Dobel klik file **`index.html`**.
3. Modul akan langsung terbuka di browser favoritmu (Google Chrome, Safari, Edge, dll) secara offline!

### Cara 2: Lewat VS Code Live Server
1. Buka folder ini di VS Code.
2. Pasang ekstensi **Live Server** (jika belum ada).
3. Klik kanan pada file `index.html` > pilih **"Open with Live Server"**.

---

## 📚 Isi Modul Belajar

1. **Peta Konsep & Mental Model:** Memahami 4 ruangan kerja Git (*Working Directory*, *Staging Area*, *Local Repo*, *Remote GitHub*).
2. **Bab 1 - Setup Awal Git di VS Code:** Terminal internal, konfigurasi `user.name` & `user.email`, serta rekomendasi ekstensi GitLens & Git Graph.
3. **Bab 2 - Step-by-Step Mulai Proyek dari Nol:** Panduan komparasi antara **Klik UI VS Code** (Source Control) dan **Perintah Terminal**.
4. **Bab 3 - Siklus Kerja Harian:** Cara kirim update (*Push*), cara ambil update (*Pull*), sinkronisasi (*Sync Changes*), dan beda `fetch` vs `pull`.
5. **Bab 4 - Bedah Tuntas Git Branching:** Konsep ranting/cabang, create branch, switch branch, merge, dan cara mudah menyelesaikan *Merge Conflict* lewat tombol pembantu VS Code.
6. **Bab 5 - Kamus Lengkap Bendera (Flags) & Istilah:**
   - Bedah makna `-u` (*upstream*), `-m` (*message* & *move/rename*), `-b`, `-d`/`-D`, `-a`/`-am`, `--amend`.
   - Terminologi: `origin`, `HEAD`, `stash`, `.gitignore`.
   - Dilengkapi filter kategori & live search (*Ctrl+K*).
7. **Bab 6 - Deploy ke GitHub Pages:** Panduan langkah demi langkah hosting web statis gratis di GitHub Pages.
8. **Bab 7 - Deploy ke Vercel:** Panduan deploy instan dengan fitur otomatis update (CI/CD) saat kita melakukan `git push` dari VS Code.
9. **Bab 8 - Simulator Interaktif & Kuis:** Generator perintah otomatis sesuai skenario kebutuhanmu + kuis interaktif dengan pembahasan jawaban langsung.

---

💡 *Semua fitur interaktif (pencarian, copy command, ganti mode gelap/terang, dan ceklis progres belajar) tersimpan otomatis di browser lokalmu.*
