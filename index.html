Aktivitas Rutin

Siklus Kerja Harian: Cara Push (Upload) & Pull (Download)

Setelah proyek terhubung ke GitHub, ini 2 situasi yang akan kamu temui setiap hari saat ngoding di VS Code:

Situasi A: Kamu Habis Ngetik & Mau Kirim Kode (Push)

Misal kamu baru selesai nambah halaman baru, ganti teks, atau benerin CSS di laptopmu:

  1. 1
    Simpan File: Tekan Ctrl + S. Di tab Source Control akan muncul huruf M (Modified).
  2. 2
    Stage File: Klik tanda plus (+) di samping Changes untuk memasukkan file ke daftar siap bungkus.
  3. 3
    Beri Catatan & Commit: Ketik pesan commit (contoh: "Beresin tombol navbar"), lalu klik tombol biru Commit.
  4. 4
    Sync Changes (Push): Klik tombol biru "Sync Changes" atau klik ikon panah putar di pojok kiri paling bawah VS Code. Kodemu langsung terkirim ke GitHub!
# Jalur Cepat Terminal:
git add .
git commit -m "Beresin tombol navbar"
git push
Situasi B: Mau Ambil Kode Terbaru dari GitHub (Pull)

Misal teman setimmu baru saja upload perubahan ke GitHub, atau kamu habis coding di komputer kantor dan mau lanjut di rumah:

  1. 1
    Buka VS Code: Buka folder proyekmu.
  2. 2
    Buka Source Control: Tekan Ctrl + Shift + G.
  3. 3
    Klik Menu Titik Tiga: Di pojok kanan atas Source Control, klik ikon titik tiga (...) > pilih menu Pull.
  4. 4
    Otomatis Tergabung: Seluruh file di VS Code laptopmu langsung ter-update dengan versi terbaru yang ada di GitHub!
# Jalur Cepat Terminal:
git pull

Apa Bedanya "git fetch" dan "git pull"?

git fetch (Cuma Ngintip & Ngecek) Git mendownload info pembaruan dari GitHub, tapi tidak langsung menggabungkannya ke file kodemu. File yang sedang kamu edit tetap aman tidak tersentuh.
git pull (Download + Langsung Tempel) Git mendownload kodenya dan langsung menggabungkannya ke dalam file di layarmu (git fetch + git merge).
Laboratorium Praktik

🌿 Branching Lab: Uji Coba Cabang & Merge Tanpa Takut Rusak

Klik tombol aksi di bawah untuk melihat bagaimana cabang (branch) bekerja dan bagaimana menggabungkannya kembali!

Analogi Sederhana: Bayangkan branch main adalah Ijazah Aslimu. Kamu mau coba-coba tanda tangan model baru. Daripada tanda tangan langsung di ijazah asli dan berisiko rusak, kamu fotokopi dulu menjadi branch coba-tanda-tangan. Di lembar fotokopi kamu bebas coret-coret. Kalau hasilnya bagus, tinggal diaplikasikan (Merge). Kalau jelek, tinggal remas dan buang (Delete Branch). Ijazah aslimu selalu aman 100%!

👉 Klik tombol "1. Bikin Branch" untuk membuat cabang uji coba baru.

Cara Menyelesaikan Merge Conflict di VS Code (3 Tombol Sakti):

Kalau kamu dan temanmu mengedit baris kode yang sama persis, Git akan berhenti dan bertanya: "Mau pakai kode siapa?". Di VS Code, kamu tinggal klik salah satu tulisan biru di atas baris kode:

Accept Current Change Gunakan kodemu yang sekarang (buang kode dari branch lain).
Accept Incoming Change Gunakan kode yang baru datang (timpa kodemu).
Accept Both Changes Pertahankan dua-duanya secara berdampingan.

Setelah memilih, cukup simpan (Ctrl + S), lalu klik tombol Commit. Masalah selesai tanpa drama!

Kamus Bahasa Manusia

📚 Kamus Lengkap Bendera (Flags) & Istilah Git

Arti di balik huruf-huruf aneh seperti -u, -m, -b, origin, dan HEAD.

-u (singkatan dari Upstream) FLAG PUSH

Artinya: "Ingat-ingat alamat ini ya, Git!"

Contoh: git push -u origin main.
Flag -u mengaitkan branch lokal di komputermu dengan branch di GitHub.
Kenapa penting? Karena kamu cukup mengetik -u satu kali saja. Pada hari-hari berikutnya, kamu cukup ngetik git push saja tanpa perlu ngetik alamat panjang lagi!

-m & -M FLAG COMMIT / BRANCH

Punya 2 Arti Tergantung Tempatnya:

• git commit -m "pesan" : m artinya Message (Pesan). Menulis catatan ringkas commit langsung di baris terminal tanpa harus membuka editor teks Vim/Nano yang rumit.

• git branch -M main : M (kapital) artinya Move / Rename. Memaksa ganti nama cabang saat ini menjadi 'main' (mengganti nama bawaan lama 'master').

-b (singkatan dari Branch Baru) FLAG CHECKOUT

Artinya: "Bikin cabang baru sekaligus langsung pindah"

Contoh: git checkout -b fitur-kontak.
Biasanya kalau mau bikin branch kita harus ketik 2 perintah: git branch nama lalu git checkout nama. Dengan flag -b, kedua langkah tersebut digabung menjadi satu detik saja!

-d & -D (Delete) FLAG HAPUS

Artinya: "Hapus Cabang (Branch)"

• -d (huruf kecil): Hapus aman. Git akan menolak jika cabang tersebut belum pernah digabungkan (merge) ke main.
• -D (huruf besar): Force Delete (Paksa hapus permanen tanpa ampun).

origin NAMA PANGGILAN

Artinya: "Nama Panggilan Singkat Buat Link GitHub"

Link repositori GitHub itu panjang (misal: https://github.com/budi/proyek-toko-baju-online.git). Daripada kamu ngetik alamat itu setiap kali push, Git memberinya julukan pendek yang dinamai origin.

HEAD INDIKATOR POSISI

Artinya: "Jarum Penunjuk: Kamu Lagi Berada di Mana"

HEAD itu seperti tanda titik merah "You Are Here" di peta mall. Menunjukkan commit atau branch mana yang saat ini sedang aktif dibuka di layarmu.

.gitignore FILE KHUSUS

Artinya: "Daftar Hitam File yang Dilarang Masuk GitHub"

File teks tempat kamu menuliskan file rahasia (seperti .env yang berisi password database) atau folder raksasa (node_modules/) agar Git pura-pura tidak melihatnya dan tidak ikut ter-upload.

git stash LACI DARURAT

Artinya: "Menyembunyikan Editan yang Belum Selesai"

Kamu lagi asyik coding tapi tiba-tiba harus pindah tugas darurat. Ketik git stash untuk menyimpan kodemu ke laci rahasia. Saat urusan selesai, ketik git stash pop untuk mengeluarkan kembali editanmu tadi!

Live Hosting Gratis

🚀 Panduan Deploy Super Detail: GitHub Pages & Vercel

Langkah demi langkah lengkap dengan panduan pencegahan error 404 dan auto-update.

Syarat Wajib Sebelum Deploy ke GitHub Pages:
  • File utama WAJIB bernama persis index.html (semua huruf kecil) dan berada di folder terluar (root).
  • Status Repositori GitHub harus Public (Kecuali kamu berlangganan GitHub Pro berbayar).
  • Penulisan nama file di HTML harus sensitif huruf besar/kecil (misal gambar bernama Foto.png jangan dipanggil foto.png).

Langkah Demi Langkah di Browser:

1

Buka Halaman Repositorimu di GitHub

Buka website github.com, login, lalu buka repositori proyek yang tadi kamu upload dari VS Code.

2

Klik Tab "Settings" (Roda Gigi)

Di deretan menu atas repositori (Code, Issues, Pull requests, Actions, Projects, Wiki, Security, Insights), klik tombol paling kanan yang bertuliskan Settings (ikon roda gigi ⚙️).

3

Pilih Menu "Pages" di Sidebar Kiri

Scroll ke bawah di bilah sisi kiri pada kelompok "Code and automation" > klik menu Pages.

4

Atur Sumber Branch: main dan /(root)

Di bawah judul Build and deployment:

• Source: Pastikan terpilih Deploy from a branch.
• Branch: Klik dropdown yang tadinya bertuliskan None → pilih main.
• Folder: Biarkan tetap /(root).
• Klik tombol Save!
5

Tunggu Proses Build (1 sampai 2 Menit)

GitHub butuh waktu sekitar 60-120 detik untuk memproses file HTML-mu. Kamu bisa melihat prosesnya di tab Actions sampai muncul tanda centang hijau.

https://username-kamu.github.io/nama-repo/
Troubleshooting: Mengapa Muncul Error 404 Not Found?

1. Tunggu sebentar: Seringkali link baru aktif setelah 2 menit. Coba refresh halaman.
2. Cek nama file: Pastikan filenya bernama index.html (bukan Index.html atau home.html).
3. Cek relative path: Di dalam HTML, panggil CSS dengan ./style.css bukan /style.css (karena ada subfolder nama repo).

Keunggulan Vercel: Sekali Deploy, Selamanya Otomatis!

Di Vercel, setiap kali kamu mengedit kode di VS Code lalu melakukan git push, server Vercel akan otomatis mendeteksi perubahan tersebut dan meng-update website onlinemu secara live dalam waktu kurang dari 15 detik! Tanpa perlu buka website Vercel lagi.

Langkah Mudah Deploy ke Vercel:

1

Buka Website vercel.com & Login dengan GitHub

Buka vercel.com > Klik Sign Up (atau Log In) > Pilih tombol Continue with GitHub. Klik izinkan otorisasi akun.

2

Klik "Add New..." lalu Pilih "Project"

Di halaman dashboard Vercel, klik tombol biru Add New... di pojok kanan atas, lalu pilih Project.

3

Pilih Repositori Proyekmu & Klik "Import"

Kamu akan melihat daftar seluruh repositori kodemu dari GitHub. Cari nama repositorimu (misal: modulbelajar), lalu klik tombol Import di sebelahnya.

4

Konfigurasi & Klik Tombol Biru "Deploy"

Untuk website HTML/CSS biasa, kamu TIDAK PERLU mengubah pengaturan apapun! Cukup langsung klik tombol biru besar bertuliskan Deploy.

ALAMAT DOMAIN VERCEL GRATIS (DILENGKAPI HTTPS):
https://nama-repo-kamu.vercel.app
